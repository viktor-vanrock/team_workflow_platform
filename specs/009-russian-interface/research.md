# Research: Русский интерфейс

**Feature**: `009-russian-interface`
**Date**: 2026-09-07
**Status**: Phase 0 complete — неопределённостей нет

## 1. Граница локализации

**Decision**: переводить весь текст, который видит пользователь в `apps/web`, `packages/competency-qa/src/ui`, `packages/platform-ui/src` и в напрямую отображаемых DoR-remediation. Не переводить внутренние логи, API-схемы, ключи, тестовые данные и код, не попадающий в UI.

**Rationale**: значительная часть интерфейса поставляется workspace-пакетами, поэтому аудит только `apps/web` оставил бы смешанный язык.

**Alternatives considered**: ограничиться shell; переводить весь репозиторий. Первое не выполняет требование, второе меняет машинные контракты и нерелевантный инженерный текст.

## 2. Архитектура перевода

**Decision**: статические фразы перевести непосредственно в компонентах, а повторяющиеся машинные значения форматировать единым `formatRuUiValue` в Platform UI. Неизвестное значение возвращается без изменения.

**Rationale**: продукт сейчас требует один язык без переключателя; полноценный i18n runtime создаст ненужную инфраструктуру. Общий formatter предотвращает расходящиеся переводы enum-кодов и сохраняет wire values.

**Alternatives considered**: отдельный словарь на каждый компонент; подключение i18n-библиотеки; изменение серверных enum. Локальные словари дублируются, библиотека избыточна, изменение enum ломает совместимость.

## 3. Терминология

**Decision**: сохранять узнаваемые имена и сокращения (`QA`, `Jira`, `GitLab`, `Mattermost`, `Hermes`, `API`, `MFA`, `OIDC`, `SLA`, `WIP`, `CI`, `ID`, `RPO`, `RTO`, `ETag`, `DoR`, `DoD`, `Mock Hub`). Обычные понятия переводить: Workspace → рабочая область, Project → проект, Work Item → рабочая задача, Session → сеанс, Approval → согласование, Evidence → подтверждающие материалы, Gate → контрольный этап, Binding → привязка.

**Rationale**: сохраняется профессиональная узнаваемость без англоязычных служебных фраз.

**Alternatives considered**: транслитерация или сохранение всех доменных существительных. Оба варианта оставляют интерфейс непоследовательным.

## 4. Контрактные коды и внешние данные

**Decision**: известные состояния показывать русской подписью; для аудиторски значимых значений допустима форма «Русская подпись (CODE)». Исходные значения в запросах, ответах, сохранённых данных и хешируемых payload не меняются. Пользовательский текст, Jira status, имена файлов, IDs, URL и model/external explanations автоматически не переводятся.

**Rationale**: перевод представления не должен менять семантику, хеши или внешний источник истины.

**Alternatives considered**: менять значения на сервере; автоматически переводить любой динамический текст. Оба подхода искажают данные и нарушают совместимость.

## 5. Ошибки и обратная связь

**Decision**: локализовать контролируемые клиентом префиксы и fallback-сообщения, сохраняя HTTP status/error code. Не определять severity поиском английского слова в строке; хранить ошибочное состояние отдельно либо проверять структурированный результат.

**Rationale**: `String(error)` и `notice.includes("failed")` дают смешанный язык и хрупкую логику после перевода.

**Alternatives considered**: скрывать техническую причину; переводить произвольный server body. Первое ухудшает диагностику, второе ненадёжно.

## 6. Даты и множественные формы

**Decision**: явно использовать русскую локаль для дат и русские подписи единиц/счётчиков. ISO и точные timestamps сохранять там, где это часть диагностического значения.

**Rationale**: `toLocaleString()` без локали и конструкции `Project(s)` оставляют англоязычный или зависящий от окружения вывод.

**Alternatives considered**: оставить системную локаль. Это делает результат непредсказуемым.

## 7. Проверка регрессий

**Decision**: обновить существующие SSR/Playwright ожидания, добавить `tests/architecture/ui-localization.spec.ts` для статического аудита JSX/prop/error-fallback строк и включить явный allowlist терминов/машинных значений.

**Rationale**: проект уже имеет широкое UI-покрытие, но оно закрепляет английские тексты. Архитектурный тест предотвращает возврат обычных английских фраз.

**Alternatives considered**: только ручной `rg`; только один новый browser-тест. Ручная проверка не предотвращает регрессию, один маршрут не покрывает UI-пакеты.
