# Модель документации

Изменений доменных сущностей, схем и migrations нет.

- **Команда разработчика**: имя alias, исходная команда, потребители, решение сохранить/удалить,
  точный альтернативный запуск. Удаление допустимо только после проверки потребителей.
- **Настройка env**: имя, назначение, процесс-потребитель, default, источник/способ передачи,
  ограничения. Runtime env, Compose-подстановки и Vite build env различаются.
- **Инструкция расширения**: тип Workspace/Project/package/Pack, предпосылки, точки регистрации,
  порядок действий и проверка результата.

Workspace и pnpm workspace не взаимозаменяемы. Новый Project начинает в DRAFT/MANUAL_ONLY;
публикация интеграций и выдача прав — отдельные операции текущей реализации.
