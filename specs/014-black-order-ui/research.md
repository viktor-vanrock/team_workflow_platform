# Research: «Чёрный орден»

## Общая тема

- **Decision**: существующий WorkspaceTheme в `apps/web/src/main.tsx` остаётся единственной точкой применения темы, `palette.mode = dark`.
- **Rationale**: provider уже охватывает local и pilot routes. Все основные контролы — MUI; native select требует отдельного baseline.
- **Alternatives considered**: CSS overlay над старой светлой темой; независимый provider для shell. Оба варианта создают несовпадающие состояния компонентов и усложняют поддержку.

## Визуальная система

- **Decision**: оригинальный dark-референс, системный serif для заголовков, системный sans для форм, CSS/встроенная геометрия для декора. Бордовые залитые кнопки и светлые металлические текстовые ссылки используют разные роли цвета.
- **Rationale**: тёмный бордовый плохо читается как небольшой текст; экспортируемый набор токенов исключает копирование случайных цветов по маршрутам.
- **Alternatives considered**: удалённые web fonts, картинки на каждом экране, темы орденов Warhammer. Не требуются выбранным направлением и добавляют зависимости либо иной дизайн.

## Обнаруженные исключения

Read-only исследование `ui_theme_research` подтвердило: светлые заливки находятся в local-workspace (header/nav), workspace-home (hero/Chip), intake (summary), findings-defects (pre) и pilot-run/readiness/recovery (main). Все остальные routes наследуют общую тему. Это позволяет сохранить существующую структуру приложения.

## Hermes

- **Decision**: арочный архивный заголовок на существующем экране предложений; настоящие предложения, состояния, revision/hash и предупреждение остаются.
- **Rationale**: в shell нет источника контекстного предложения, поэтому перенос фиктивной рекомендации из эскиза недопустим.
- **Alternatives considered**: статическая боковая рекомендация, новый backend endpoint. Первый вариант вводит пользователя в заблуждение, второй не относится к оформлению.

## Проверка

- **Decision**: сохранить 9 browser journeys 013; дополнить их отдельным визуальным smoke по реальным styles, контрасту, нативному select, ширине и отсутствию запросов к внешним ресурсам.
- **Rationale**: проверки наблюдаемого поведения защищают функциональность; цветовые snapshots отдельных tokens без проверки DOM недостаточны.
- **Alternatives considered**: только screenshot snapshots; полный backend regression всех feature. Первое не проверяет действия, второе не соответствует ограниченному визуальному изменению.
