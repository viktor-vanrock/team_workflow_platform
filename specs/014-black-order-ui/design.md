# Зафиксированный дизайн: «Чёрный орден»

Выбор пользователя 2026-09-09. Источник — первоначальный вариант «Чёрный орден» из обсуждения, до пяти стилизаций орденов Warhammer. [Визуальный референс](design-reference.png).

## Характер

Закрытый орденский архив: угольные поверхности, тёплые страницы текста, потемневшее серебро с тёплой патиной, бордовый сургуч, арочные ниши и тонкие двойные рамки. Продуктовое имя в оболочке — «Архив ордена», назначение — рабочее пространство QA.

## Роли цвета

| Роль                            | Значение  |
| ------------------------------- | --------- |
| Холст                           | `#111113` |
| Панель                          | `#1b1a1c` |
| Приподнятая поверхность/контрол | `#242125` |
| Навигация                       | `#0c0c0f` |
| Основной текст                  | `#e8dfce` |
| Вторичный текст                 | `#b0a99e` |
| Декоративная рамка              | `#48413c` |
| Значимая граница контрола       | `#8b7b6b` |
| Металл / ссылки                 | `#baaa8c` |
| Бордовая кнопка                 | `#863640` |
| Hover кнопки                    | `#9b4551` |
| Фокус                           | `#d9bd8d` |

Декоративная рамка не обозначает интерактивную границу. Контролы используют более контрастный отдельный цвет. Ошибки — светлый коралл, предупреждения — янтарь, успех — приглушённый светлый зелёный, информация — светлый стальной голубой; текстовые статусы сохраняются.

## Типографика и форма

- Заголовки: Cormorant Garamond 500; текст интерфейса: Manrope 400/500/600. Шрифты с кириллицей поставляются локально вместе с лицензиями OFL.
- Формы и таблицы сохраняют плотность и выравнивание. Арки используются на входе, главной и Hermes, а не на каждом поле.
- Кнопки и панели имеют малое скругление; основное действие — бордовая заливка со светлым текстом.
- Декоративные углы, печать и арки не имитируют реальную подпись или готовность: пользовательское заключение показывается только из данных.
- На узком экране декор сокращается, содержание переносится, действия остаются видимыми.
- Без внешних web fonts, фоновых иллюстраций, мигающих индикаторов и постоянной анимации.

## Повторная реализация по исходному макету

Коррекция пользователя 2026-09-09: первый UI выглядел темнее и проще выбранной картинки.
Источником визуальных значений служит исходный `fantasy-workspace.html`, вариант
`data-theme="dark"`, а не только таблица базовых цветов. Сравнение проводится на
ширине референса — 1024px.

- Боковая колонка: 172px; верхняя строка: 50px; внутренние отступы: 26px.
- Заголовок страницы: 43px, межбуквенный интервал 1px. Заголовок архивной карточки: 30px.
- Холст: тёплое пятно `#30212788` в правом верхнем углу и диагональная фактура `#d6c6a303` поверх `#111113`.
- Панель: `linear-gradient(112deg, #242022 0%, #1b1a1c 58%, #171719 100%)`.
- Двойная рамка: внешний `#6d5c4c`, внутренний `#51443a`, углы 27px цвета `#b49c74`.
- Основная кнопка: `linear-gradient(#893b46, #662831)`, бордюр `#b77776` и две внутренние линии.
- Hermes: колонка 207px, арка, фон `#161317` с радиальным `#65363b55`, орбита 91px.
- На мобильном экране колонки складываются; сохраняются 44px основные действия, читаемый focus и поля 16px.

Вместо демонстрационных QA-142 и подсказки про истёкшую карту используются реальные
разделы и данные платформы. Карточка Hermes не выдаёт декоративный текст за предложение;
переход из выбранного запроса передаёт его ID в существующую форму просмотра предложений.

## Границы

Тема одна, без переключателя. Продукт сохраняет привычные слова «Запросы», «Очередь», «Проверки» и «Заключение». Эмблемы/названия Warhammer и игровые ранги не добавляются.
