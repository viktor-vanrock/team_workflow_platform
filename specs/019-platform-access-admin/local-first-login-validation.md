Они входят в 42 теста выше. Бизнес-права и корпоративный bootstrap проверяются отдельно.
- Playwright `tests/e2e/019/access-browser.spec.ts`: 5 сценариев пройдено. Проверены отметка глобального администратора, источник «первый локальный вход», редактирование ролей, локальные запреты, корпоративная админка и ожидание прав. Browser fixtures моделируют API; фактические DB-транзакции проверены интеграционными тестами.
- Root TypeScript, ESLint изменённых TypeScript-файлов, architecture (24 проекта), `git diff --check`: успешно.
- Локальный Vite production build: успешно. Существующее предупреждение о static/dynamic import project-dialogue не блокирует сборку.

Итого: 69 различных Vitest-тестов и 5 браузерных сценариев. Полный набор всех тестов репозитория не запускался.
