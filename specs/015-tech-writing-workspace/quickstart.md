# Проверка локального примера

Из этого worktree с Node 24.20.0 и pnpm 11.21.0 выполнить `pnpm dev:pilot:up`. Команда использует существующий Compose project `awp-local-pilot-dev`, применяет аддитивные миграции/seed без удаления volumes. Web: http://localhost:55173, API: http://localhost:5300.

1. На экране входа выбрать «Технический писатель» (`writer.docs`), войти без пароля через локальную persona.
2. Сравнить главную, «Мои документы» и задания сервиса ALPHA. Открыть черновик или создать новый пример, ввести текст, сохранить и обновить страницу.
3. Отправить на ревью. Через «Сменить роль» войти как «Лид технических писателей» (`lead.docs`).
4. На главной/в очереди ревью открыть документ, написать замечание и вернуть на доработку.
5. Войти писателем, прочитать замечание, исправить текст, сохранить и снова отправить на ревью.
6. Войти лидом и утвердить; проверить текущую версию и историю. Вновь изменить текст писателем — действующее утверждение снимается.
7. Для повторения создать новое задание писателем. Готовые примеры не требуют сброса БД.
8. Войти «Исполнитель QA · ALPHA»: проверить прежние QA главную и список запросов.

Серверные отрицательные проверки, повторный seed, проверка после перезагрузки и фактические команды фиксируются в [validation.md](validation.md). Контракты: [HTTP](contracts/http.md), [модель](data-model.md).
