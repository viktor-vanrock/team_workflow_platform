## Границы проверки и оставшиеся ограничения

- Это экспертный аудит и проверка сценариев, без исследования группы пользователей. Сокращение времени обучения не измерялось.
- Полный CI, все legacy browser journeys 002–007 и корпоративная end-to-end авторизация не запускались. Их затронутые selectors/пути обновлены; корпоративные маршруты сохранены.
- Глубокие административные формы, exact refs/hashes и серверная модель подготовки проверок не переработаны; доступ к ним объяснён и вынесен в дополнительные разделы.
- API не предоставляет каталог восстановления всех черновиков. Перезагрузка страницы требует нового входа; незавершённое локальное резюме не восстанавливается автоматически. При неизвестном результате доступна проверка текущего draft без повторного создания; ограничение описано в руководстве.
- В локальных эмуляторах остались созданные для проверки учебные запросы/команды. Продуктивные интеграции и данные не использовались.
