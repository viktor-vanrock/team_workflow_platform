# ADR-0011: Общая предметная команда во всех проектах

Дата: 2026-09-09. Статус: принят по запросу владельца продукта в feature 016.

Роль описывает функцию и предметную область. Два человека QA имеют одну роль `qa-executor` в рабочей области; конкретный проект выбирается отдельно. Роль аудитора удаляется из действующего набора ролей ADR-0004; исторический журнал сохраняется.

Workspace-level role assignment может явно иметь `project_access_scope=ALL_PROJECTS` и потолок классификации. Этот признак служит источником выдачи точных проектных entitlements при регистрации, а не дополнительным путём обхода авторизации. Core продолжает проверять пересечение membership, project entitlement, role permission и classification; явный DENY имеет приоритет. Новые права записываются одной транзакцией с onboarding и входят в starter entitlement hash/references.

Миграция 0205 расширяет role_assignments, сохраняя SELECTED_PROJECTS по умолчанию. Local seed v3 сохраняет UUID людей и фиксированные UUID назначений, удаляет живые связи аудитора, создаёт второго QA и revisioned grants существующим проектам. Legacy subject keys с именами проектов остаются техническими ключами совместимости. Ранее отозванные entitlements не активируются заново.

Корпоративная group policy может явно выбрать ALL_PROJECTS с пустым projectIds и точным набором roleKeys. Проверка текущих per-project entitlements остаётся обязательной. Неявный wildcard, доступ только по членству и распространение в чужую рабочую область запрещены. Для другого предметного pack нужны его роли/permissions; feature не объявляет новой модели междоменных данных.

Rollout: migration → seed → перезапуск API/IdP/worker/web → новый вход. Reset базы не требуется. Rollback схемы удаляет только новые поля; уже выданные entitlements остаются явными и требуют отдельного отзыва при откате прав. Удалённый аудитор автоматически не восстанавливается. Аудит/историческое авторство не удаляются.

Проверки: отдельная PostgreSQL база, два QA в ALPHA/BETA, DENY/чужая область/отзыв членства, повторный seed, регистрация и replay, корпоративная policy, браузерные переходы. Конституция III/IX/XI сохраняется без поправки.
