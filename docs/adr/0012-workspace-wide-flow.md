# ADR 0012: Общая работа команды по проектам

Дата: 2026-09-09. Статус: принято. Spec Kit: 017-workspace-wide-flow.

Рабочая область обслуживается общей командой. Проект — атрибут задачи и граница авторизации, а не переключаемая пользовательская сессия. Общая очередь использует существующую разрешённую проекцию AUTHORIZED_PORTFOLIO. Общий каталог запросов и Hermes получают только разрешённые сущности, включая проверку классификации. URL карточки задаёт проект и задачу; прямой вход и история браузера сохраняют назначение перехода.

Канонические роли: system-administrator (владелец области и администратор интеграций) и reader (читатель и наблюдатель). Люди остаются отдельными идентичностями. Миграция 0210 переименовывает действующие назначения и увеличивает row_version; исходные значения сохраняются в role_merge_0210_snapshot. Scope, DENY, срок, отзыв, классификация и ограничения entitlement остаются действующими. Версионный локальный seed 4 объединяет административные функции через обычные ревизии прав. Старые имена распознаются при чтении истории и корпоративных групп; новое имя само по себе не даёт разрешений.

Изменение основы полномочий намеренно делает старое ожидающее согласование устаревшим. Требуется новое согласование точного действия; запрещено переписывать хеши существующих approvals. Автоматический down запрещён: обратное разделение ролей требует проверенного восстановления снимка с учётом новых назначений. События, документы, задачи и исторические авторы не изменяются.

UI использует объединение прав только для отображения меню. Управление сущностью получает права её проекта, сервер повторно проверяет живые полномочия. Читатели просматривают доступные материалы; изменяющие команды скрыты или отключены. Техписатели сохраняют отдельную предметную область и существующий процесс авторства/ревью.

Hermes показывает именованный список запросов, черновиков и обращений. Выбор загружает сохранённую историю предложений, не запускает обработку. Смена выбора отменяет старый запрос и очищает результаты.
