# Black Order fonts

The approved prototype uses Cormorant Garamond and Manrope. These copies are served
by the application's own origin; there is no Google Fonts request at runtime.

| File                         | Family             | Weight |
| ---------------------------- | ------------------ | ------ |
| `cormorant-garamond-500.ttf` | Cormorant Garamond | 500    |
| `manrope-400.ttf`            | Manrope            | 400    |
| `manrope-500.ttf`            | Manrope            | 500    |
| `manrope-600.ttf`            | Manrope            | 600    |

Downloaded 2026-09-09 from the Google Fonts stylesheet used by the prototype:
https://fonts.googleapis.com/css2?family=Cormorant+Garamond:wght@400;500;600&family=Manrope:wght@400;500;600&display=swap

Both families use the SIL Open Font License 1.1. The original notices are preserved
in `cormorant-garamond-OFL.txt` and `manrope-OFL.txt`, from their respective Google
Fonts source directories: https://github.com/google/fonts/tree/main/ofl/cormorantgaramond
and https://github.com/google/fonts/tree/main/ofl/manrope.
